## 功能

- 广告
  - 去启动页广告
  - 去信息流广告
  - 去回答列表广告
  - 去评论广告
  - 去分享广告
  - 去回答底部广告
  - 去搜索广告
- 其他
  - 过滤视频 / 文章 / 想法
  - 去信息流会员推荐
  - 去回答圈子
  - 去商品推荐
  - 去相关搜索
  - 去关键字搜索
  - 直接打开外部链接（含 Ex）
  - 禁止切换色彩模式
  - 显示卡片类别
  - 状态栏沉浸
  - 禁止进入全屏模式
  - 第三方登录
  - 禁止自动刷新
- 界面净化
  - 不显示小红点
  - 隐藏会员卡片
  - 隐藏热点通知
  - 精简文章页面
  - 隐藏置顶热门
  - 隐藏混合卡片
- 导航栏
  - 隐藏首页 / 看山 / 发布 / 消息 / 我的
  - 禁用活动主题
- 回答
  - 移除下一个回答按钮（旧 + 新版短容器）
- 自定义过滤
- WebView
  - 开启WebView调试
  - 移除水印（页面 / 视频 / 混合容器）
  - 图片换源去水印（实验性）
  - 去除回答页面关注头像
  - 注入JS脚本
- 临时文件
  - 清理 / 自动清理 / 静默清理
- 调试
  - 隐藏功能加载失败提示
  - 记录 Hook 触发日志

## 帮助
[Github Wiki](https://github.com/shatyuka/Zhiliao/wiki)

需要支持 libxposed API 102 的框架（LSPosed 2.1.0 及以上）。

开发和新版知乎适配请参阅 [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)。
